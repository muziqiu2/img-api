# 后台更新功能移除说明

> 2026-09-23｜提交 `5c91bb8`｜生产已部署并验证

## 背景

项目已脱离上游 lsky-pro，后台的「系统更新」功能不再有使用场景。核查后发现它不只是「用不上」，
而是同时构成**失效的假象**与**真实的攻击面**，故整体摘除（而非仅隐藏界面）。

## 为什么删

### 1. 功能已失效，但界面在骗人

上游版本接口现已关闭公开访问：

```bash
$ curl -s -o /dev/null -w "%{http_code}\n" https://api.lsky.pro/v2/versions
403
$ curl -s https://api.lsky.pro/v2/versions
{"message":"Authentication failed."}
```

而失败在界面上的表现却是「已是最新版本」。完整链路：

```
UpgradeService::getVersions()   非 2xx → 抛异常「无法请求升级服务器」
  → SettingController::checkUpdate()  catch → $this->fail($e->getMessage())
    → Result::response()   固定返回 HTTP 200，只把 status 置为 false
      → 前端 setting/index.blade.php 判的是 response.data.status
        → 为 false → 走 else 分支 → 显示「{{版本号}} 已是最新版本」
```

**即那个「已是最新」是假的** —— 实际是一次失败的请求被 UI 吞掉了。

### 2. 它是一条远程写入通道

`UpgradeService::upgrade()` 的核心动作：

```
从外部 API 拉取文件清单 → 下载各文件 → 写入 base_path() 对应路径
  → Artisan::call('migrate', ['--seed' => true])
```

关键在它的「安全校验」：

```php
if ($file['md5'] !== md5_file(base_path($this->temp).'/'.$file['pathname'])) {
    throw new \Exception("补丁文件 {$file['pathname']} 校验失败。");
}
```

**这个 md5 来自同一个 API 响应（`$result`）** —— 校验值与文件内容由同一来源提供。
攻击者控制响应内容并附上匹配的 md5 即可通过。它只能防传输损坏，防不了篡改。

对一个已脱离上游的站点而言，这等于白白留着一条
**「外部控制方可在项目根目录写入任意 PHP 文件」的通道**，而收益为零。

### 3. 运维隐患

```php
$this->http = Http::baseUrl(self::ApiUrl)->withOptions(['timeout' => 1800])->timeout(1800);
```

外部接口无响应时，该请求可占住一个 PHP-FPM worker 最长 **30 分钟**。
而后台设置页每次打开都会自动触发一次这个请求（`getVersion()` 在页面加载时无条件执行）。

## 改动清单

| 文件 | 动作 | 备注 |
|---|---|---|
| `app/Services/UpgradeService.php` | 整体删除 | 164 行 |
| `app/Console/Commands/Upgrade.php` | 整体删除 | 45 行，`lsky:upgrade` 命令 |
| `routes/web.php` | 删 3 条路由 | `admin.settings.check.update` / `upgrade` / `upgrade.progress` |
| `app/Http/Controllers/Admin/SettingController.php` | 删 3 方法 + 2 个 use | 方法：`checkUpdate` / `upgrade` / `upgradeProgress`；use：`ConfigKey`、`UpgradeService` |
| `resources/views/admin/setting/index.blade.php` | 删 UI 与 JS | 「系统升级」区块、`update-tpl` 模板、75 行 JS；291 → 185 行 |
| `resources/views/admin/console/index.blade.php` | 删 3 处外链 | 顺带清理指向官方的官网 / 使用手册 / 仓库地址 |

### 保留项

**`ConfigKey::AppVersion` 未删除。** 它不属更新功能专属，仍被两处只读展示引用：

- `admin/setting` 页的当前版本号
- `admin/console` 页的「软件版本」

默认值定义在 `config/convention.php`。

注意区分：`SettingController` 里的 `use App\Enums\ConfigKey;` 只被删除的方法用过，所以要删；
但**视图里用的是全限定名 `\App\Enums\ConfigKey::AppVersion`，与控制器那个 use 无关**。
