# 品牌残留清理说明

- 日期：2026-09-23
- 提交：`59aed18`（本地 = 远端 = 生产，三方 md5 一致）
- 范围：代码与界面中的**对外链接 + 品牌标识**；不含已确认保留项

## 一、背景

上一轮摘除后台更新功能（`e0d0d79`）后，代码与界面里仍留有多处指向上游 `lsky.pro`
的链接和品牌字样。对一个已脱离上游维护的站点，这些既没有用途，也会让人误以为
是在使用官方产品、可从官方获取支持。

清理原则：

- **指向官方的链接** → 删除或替换为中性示例
- **以官方产品自居的品牌标识**（安装页标题、后台示例、配置默认值）→ 改为本站命名或中立表述
- **来源声明**（"基于……搭建"）与**合规文本**（GPL 3.0）→ 保留，不属残留
- **内部实现标识**（CLI 命令名）→ 保留，用户不可见且改动涉及不可测流程
