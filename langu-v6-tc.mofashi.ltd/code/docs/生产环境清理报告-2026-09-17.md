## 5. 过程中发现的问题（建议后续关注）

1. **首页是静态 `public/index.html`，不是 Blade 视图。** nginx 的 `index` 指令把 `index.html` 排在 `index.php` 前面，所以修改 `resources/views/welcome.blade.php` 或 Laravel 路由 **不会**影响首页。后续改首页必须直接改 `public/index.html`。这是本次排查中最重要的一个发现。

2. **`storage/temp` 残留说明曾有一次在线升级被中断。** 正常情况下 `UpgradeService` 升级成功后会自行清理该目录。如果这不是有意中断，建议复查升级流程。

3. **`storage/app/uploads -> /home/nas/图床/` 目前是悬空软链**（服务器上 `/home/nas` 不存在）。生产实际使用 Custom(OpenList S3) 策略，不走本地储存，因此当前无影响；但若将来启用「本地储存」策略，写入会失败，需要先修正该挂载。

4. **`public/png`、`public/jpg`、`public/webp`、`public/jpeg` 是 4 个普通文件**（内容是真实图片字节，mtime 分别为 2023-04-15、2023-03-01、2026-08-15、2023-09-19）。推测原本是指向 NAS 图片目录的符号链接，被某次复制/同步实体化成了文件。代码中无引用，但来源未查清，故保留未动。

5. **`/admin` 返回 404 属正常**，因为 `admin` 本身不是路由；后台入口为 `/admin/console`、`/admin/settings`、`/admin/strategies` 等（未登录会 302 到 `/login`）。

6. **验收请求会新增会话文件。** 清理前后 `storage/framework/sessions` 由 19 个变为 26 个，新增的均带 19:41–19:44 时间戳，来自本次验收的 HTTP 请求（`/login` 会下发 CSRF 会话），属正常运行时行为。
